# Audio sources and rights assessment

No online provider is integrated. Verify current terms, geographic availability and actual rights before shipping. A public URL, metadata entry, CC badge, or user account alone does not establish all necessary recording, composition, streaming, offline and commercial rights. Obtain legal review and keep provenance and licences per item.

| Candidate | Uses / restrictions | Recommendation |
|---|---|---|
| User-selected files | User must have rights; no blanket redistribution permission; no network required | First source; SAF read grants, no re-upload |
| Artist-authorized catalog | Written agreements must cover recording and composition, territories, streaming, offline, attribution, revocation and commercial use | Best long-term independent catalog; establish contracts and takedown process |
| Internet Archive | Item-specific rights and access conditions; public availability is not a licence; verify attribution, download, territory and commercial use per item | Research only, deny unknown rights |
| Jamendo | API and catalog terms apply; streaming, offline and commercial permissions must be separately confirmed | Investigate [API terms](https://devportal.jamendo.com/api_terms_of_use); no integration without approval |
| MusicBrainz | [Metadata](https://musicbrainz.org/doc/About/Data_License), not audio; core and supplementary datasets have different licences | Optional metadata enrichment with rate-limit and attribution compliance |
| ListenBrainz | Listening history service; [API](https://listenbrainz.readthedocs.io/en/latest/users/api/) and privacy terms apply; not audio rights | Optional explicit opt-in integration only |
| Spotify Web API | [Developer terms and restrictions](https://developer.spotify.com/policy), access and quotas apply; metadata does not authorize independent audio streaming or offline access | Not a primary catalogue; assess any optional integration separately |
| Self-hosted user library | User controls server and content; permissions and network security still matter | Future opt-in source, no default public server |
