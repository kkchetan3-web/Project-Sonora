# API and service requirements

None are configured or required for user-selected local playback. See [AUDIO_SOURCES.md](AUDIO_SOURCES.md) for provider-specific licensing assessment. A production streaming catalogue requires verified recording and composition rights, per-territory availability, explicit stream/offline permissions, attribution and revocation, plus authorized delivery and storage. MusicBrainz is metadata, not streaming rights; Spotify's API is not a licence for independent Spotify audio playback.

Social features require authenticated accounts, access control, consent, privacy/deletion workflows, abuse prevention and secure real-time synchronization. AI needs a separately configured provider or supported local model, explicit cost/privacy disclosure and graceful unavailability. Lyrics, translations, videos, podcasts and audiobooks each require appropriate rights or user-supplied data. No credentials are present or requested.
